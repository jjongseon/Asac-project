# 보드게임 펀딩의 성공 규모 예측 (Gamefound)

캠페인 시작 후 3일간의 댓글 반응과 썸네일 이미지, 기본 정보만으로 최종 모금액을 예측할 수 있는지 확인한 프로젝트입니다.

ASAC 빅데이터 분석 11기 · 머신러닝 4조 (5인 팀) · 2026.06

## 왜 만들었나

Kickstarter와 Gamefound를 합친 보드게임 크라우드펀딩 규모는 약 3.76억 달러입니다. 창작자 입장에서는 런칭 전에 성공 가능성을 가늠할 지표가 없어서, 캠페인 초기 반응만으로 최종 모금액을 예측하는 모델을 만들었습니다.

## 결과

| 변수 조합 | MAE | R² |
|---|---|---|
| Base (기본 정보) | 25,120 | 0.83 |
| + 이미지 (대표색) | 24,274 | 0.83 |
| + 댓글 감성분석 | 22,151 | 0.85 |
| + 장르 구간화 | **19,750** | **0.89** |

최종 모델 XGBoost · Base 단독 대비 MAE 약 21% 개선

## 핵심 판단: backers를 예측 변수에서 뺀 이유

후원자 수(backers)는 최종 모금액과 상관계수 **0.96** (p = 2.28e-270)이었습니다. 넣으면 성능이 크게 오르지만 쓰지 않았습니다.

1. 유튜브 조회수 예측에 구독자 수를 넣는 것과 같은 **결과 유출**입니다.
2. 펀딩이 끝나야 확인할 수 있는 값이라, "런칭 전 의사결정을 돕는다"는 목적과 **시점이 맞지 않습니다.**

## 파이프라인

```
Gamefound 크롤링
  → 전처리 (펀딩 상태·타입 정제, 1.5 IQR 컷오프, 목표변수 로그 변환)
  → 특징 생성 (댓글 / 이미지 / 기본 정보)
  → XGBoost
```

**댓글 — 캠페인 시작 후 3일간**

3일차 초기 반응만으로 성공 가능성을 상당 부분 예측할 수 있다는 선행 연구(Kindler et al., *Early prediction of the outcome of Kickstarter campaigns*)를 근거로 기준을 잡았습니다.

- XLM-RoBERTa 감성 3분류 — BERT와 댓글 100건을 대조한 뒤 채택 (다국어 댓글의 중립 분류가 더 안정적)
- Gemini API 의도 6종 분류 (배송 / 제품질문 / 응원 / 불만 / 제안 / 스팸)
- BERTopic 주제 7종 비지도 분류 (BGE-M3 → UMAP → HDBSCAN)

**썸네일 이미지**

- Edge density · 채도 · 명도 · 대비
- 대표 색상 4종 추출 후 IRI 형용사 이미지 스케일로 감성 형용사 변환

## 내 역할 (이종선 · 조장)

- backers 변수 제외, 초기 3일 댓글 기준 설정 등 예측 변수 설계 의사결정
- 프로젝트 진척 관리

## 실행 참고

`01_Src/processed/2.1_comment_gemini.ipynb`는 Gemini API 키가 필요합니다. 키는 저장소에 포함되어 있지 않으며, 직접 발급받아 같은 경로에 `api_key.txt`로 저장한 뒤 실행하세요.

## 한계

극단값을 1.5 IQR로 잘라낸 모델이라 '메가 히트' 펀딩은 예측하지 못합니다. 표본을 늘리고 메가 히트 전용 모델을 따로 두는 방향을 고려하고 있습니다.
