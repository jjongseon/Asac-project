# 보드게임 펀딩의 성공 규모 예측 (Gamefound)

캠페인 시작 후 3일간의 댓글 반응 + 썸네일 이미지 + 기본 정보로 최종 모금액을 예측.

ASAC 빅데이터 분석 11기 · 머신러닝 4조 (5인) · 2026.06

## 배경

- Kickstarter + Gamefound 보드게임 펀딩 규모 약 3.76억 달러
- 창작자가 런칭 전에 성공 가능성을 가늠할 지표가 없음

→ 캠페인 초기 반응만으로 최종 모금액을 예측할 수 있는지 확인해본 프로젝트

## 결과

| 변수 조합 | MAE | R² |
|---|---|---|
| Base (기본 정보) | 25,120 | 0.83 |
| + 이미지 (대표색) | 24,274 | 0.83 |
| + 댓글 감성분석 | 22,151 | 0.85 |
| + 장르 구간화 | **19,750** | **0.89** |

최종 모델 XGBoost · Base 단독 대비 MAE 약 21% 개선

## 핵심 판단 — backers를 예측 변수에서 뺀 이유

후원자 수(backers)는 최종 모금액과 상관계수 **0.96** (p = 2.28e-270). 넣으면 성능이 크게 오르지만 쓰지 않음.

- 유튜브 조회수 예측에 구독자 수를 넣는 것과 같은 **결과 유출**
- 펀딩이 끝나야 확인 가능 → "런칭 전 의사결정" 이라는 목적과 **시점이 안 맞음**

## 파이프라인

```
Gamefound 크롤링
  → 전처리 (펀딩 상태·타입 정제, 1.5 IQR 컷오프, 목표변수 로그 변환)
  → 특징 생성 (댓글 · 이미지 · 기본 정보)
  → XGBoost
```

### 댓글 — 캠페인 시작 후 3일

3일차 초기 반응만으로 성공 가능성을 상당 부분 예측할 수 있다는 선행 연구를 근거로 기준 설정
(Kindler et al., *Early prediction of the outcome of Kickstarter campaigns*)

- **XLM-RoBERTa** 감성 3분류 — BERT와 댓글 100건 대조 후 채택 (다국어 댓글의 중립 분류가 더 안정적)
- **Gemini API** 의도 6종 분류 (배송 / 제품질문 / 응원 / 불만 / 제안 / 스팸)
- **BERTopic** 주제 7종 비지도 분류 (BGE-M3 → UMAP → HDBSCAN)

### 썸네일 이미지

- Edge density · 채도 · 명도 · 대비
- 대표 색상 4종 추출 → IRI 형용사 이미지 스케일로 감성 형용사 변환
